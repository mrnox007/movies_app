# 🎬 Movie App

A cross-platform movie discovery mobile application built with **Flutter** and **Dart** as a collaborative team project. The app integrates with RESTful APIs to browse movies, view detailed information, explore genres, and check cast members with a clean, responsive UI.

## ✨ Features
- **Movie Discovery:** Browse trending, popular, and categorized movies with high-resolution posters.
- **Movie Details Screen:** View full movie summaries, ratings, genres, and cast details.
- **Splash & Onboarding:** Smooth introductory flow and intuitive navigation.
- **RESTful API Integration:** Dynamic data fetching and JSON parsing for real-time movie data.
- **State Management:** Efficient UI state handling using BLoC architecture.

## 👨‍💻 My Contributions
- Designed and implemented the **Movie Details** feature, including the movie summary, genres, and cast sections.
- Integrated API endpoints and connected UI components using `BlocBuilder`.
- Collaborated within a Git workflow using feature branches, pull requests, and merge conflict resolution.

## 🛠️ Tech Stack
- **Framework:** Flutter
- **Language:** Dart
- **State Management:** BLoC (`flutter_bloc`)
- **Networking:** RESTful APIs (`http` / `Dio`)
- **Version Control:** Git & GitHub (Team Workflow)

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/mrnox007/movie_app.git](https://github.com/mrnox007/movie_app.git)
   ```

2. **Navigate to the project directory:**
   ```bash
   cd movie_app
   ```

3. **Install dependencies:**
   ```bash
   flutter pub get
   ```

4. **Run the app:**
   ```bash
   flutter run
   ```
